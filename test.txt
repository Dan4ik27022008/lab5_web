Перший запит (має бути X-Cache: MISS)
curl -i -s http://127.0.0.1:80/200

Повторний запит (має бути X-Cache: HIT)
curl -i -s http://127.0.0.1:80/200

Запит неіснуючого коду (має бути 404)
curl -i -s http://127.0.0.1:80/999

Недозволений метод (має бути 405)
curl -i -s -X POST http://127.0.0.1:80/200

Замінює кешовану картинку на вказану
curl -i -s -X PUT http://127.0.0.1:80/418 --data-binary "@cache/200.jpg"

# Видалення наявної картинки (200)
curl -i -s -X DELETE http://127.0.0.1:80/418

# Повторне видалення відсутньої картинки (404)
curl -i -s -X DELETE http://127.0.0.1:80/418
